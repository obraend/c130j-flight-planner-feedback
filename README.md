# C-130J Flight Planner — feedback

Bug reports and feature requests for the C-130J Flight Planner for DCS World.

- [Open the planner](https://c130j-flight-planner.netlify.app)
- [Try the beta](https://beta--c130j-flight-planner.netlify.app)
- [Browse existing reports](https://github.com/obraend/c130j-flight-planner-feedback/issues)
- [Report a bug or suggest a feature](https://github.com/obraend/c130j-flight-planner-feedback/issues/new/choose)

Search existing reports first. If yours is new, choose the bug-report or feature-request form.
A GitHub account is required to submit feedback. Reports and attachments are public.

For a bug, include the steps to reproduce it, what you expected, what happened, and the planner
version shown in the page footer. A screenshot and the relevant route, cargo or fuel settings
help reproduce calculation problems. The planner does not automatically attach or upload your plan.

This repository hosts feedback only. The application source is maintained separately.
Feedback documentation and templates here are available under the [MIT License](LICENSE).

For the DCS World simulation only — not for real-world flight planning.
